1 五分钟上手

1.1 打开软件

双击桌面快捷方式「市场监测」。程序会在本机启动一个本地服务并自动打开窗口，首次启动需要 3~10 秒拉取行情。

不需要联网账号、不需要管理员权限。所有数据保存在程序目录的 data\ 下；关掉窗口程序即退出，下次打开继续用本地历史。

1.2 界面的四个区域

区域位置作用
顶部导航左上角切换六大视图：行情 / 板块 / 宏观 / 债券 / 黄金 / 关联分析
市场状态灯导航右侧显示 A 股、港股、美股、ETF、期货、利率、汇率当前是「交易中 / 休市 / 已收盘」
工具栏右上角搜索标的、刷新频率、立即刷新、检查更新、下载历史
内容区主体随导航切换；顶部是主要图表，底部是分组卡片

1.3 三个最常见用法

用法一：看一个标的的现状

1
在右上角搜索框输入名称或代码（如 贵州茅台 或 600519），回车。
2
主图切到该标的，默认显示「日线」，可点上方「分时 / 资金流」切换。
3
右侧「详情」面板给出最新价、涨跌幅、今开/最高/最低、成交量、成交额、更新时间与数据源。
4
下方「1W / 1M / 3M / 6M / 1Y / 3Y / ALL」切换时间跨度；鼠标滚轮可缩放日线。

用法二：看今天哪个行业在涨

1
点导航「板块」。
2
右上选择口径：「新浪行业」（49 个行业，金融拆成 4 类）或「证监会」（5521 只股票，门类 → 次类 → 大类）。
3
左侧点行业名 → 右侧显示该行业前 50 只个股的树图：方块面积 = 总市值，颜色 = 涨跌幅。
4
点任意方块 → 下钻到个股（分时、日线、资金流、历史区间），左上「返回板块」回到热力图。

用法三：判断两个标的是否同涨同跌

1
点导航「关联分析」。
2
左侧勾选 2~8 个标的（可搜索）；上方选择「滚动窗口」（20 / 60 / 120 日）与「观察区间」（1Y / 2Y / 3Y / ALL）。
3
右侧曲线即时算出 6 个相关性指标 + 综合关联指数，下方卡片给出最新值与「基本不相关 / 弱相关 / 中等相关 / 强相关」判定。
4
在同一页下方，可用「LightGBM 概率预测」预测第一个标的下一期的涨跌区间概率。

3 指标字典：定义、算法与作用

每个指标按「是什么 → 怎么算 → 怎么看 → 注意什么」四段说明。

3.1 行情基础指标

涨跌幅（%）

  • 定义：最新价相对上一交易日收盘价的变化百分比。
  • 算法：(最新价 − 昨收) ÷ 昨收 × 100%；期货、外汇用同一口径。
  • 作用：最直观的强弱度量，是卡片颜色与树图着色的依据。
  • 注意：不同市场涨跌幅限制不同（A 股主板 ±10%、创业板/科创板 ±20%），跨市场比较大小时要留意。

成交量 / 成交额

  • 定义：当期成交的股数（成交量）与金额（成交额）。
  • 算法：直接取数据源字段；A 股单位为手（1 手 = 100 股）与元，本程序统一换算为「股 / 元」后按量级显示（万 / 亿）。
  • 作用：验证价格变化是否有量能配合；放量上涨与缩量上涨含义不同。

MA20（20 日均线）

  • 算法：最近 20 个交易日收盘价的算术平均，逐日滚动。
  • 作用：中期趋势参考线。价格在 MA20 之上视为强势，跌破视为走弱。
  • 注意：均线是滞后指标，震荡市里容易反复穿越，不构成买卖信号。

3.2 关联分析指标

所有相关性指标都落在 [−1, 1]：+1 完全同向，−1 完全反向，0 无关。

Pearson 线性相关

  • 定义：两个标的日收益率在窗口内的线性相关程度。
  • 算法：
    r = Σ[(xᵢ − x̄)(yᵢ − ȳ)] ÷ √(Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)²)
    x、y 为窗口内两个标的的日收益率（不是价格，避免趋势造成的伪相关）。
  • 作用：最常用的相关性度量，衡量「一起动」的程度。
  • 注意：对异常值敏感，单日暴涨暴跌会显著拉低相关系数；只反映线性关系，非线性关系会低估。

Spearman 秩相关

  • 定义：把收益率换成排名后计算 Pearson，即秩相关。
  • 算法：对窗口内每列取秩次（并列取平均秩），再套用 Pearson 公式。
  • 作用：抗极端值。当某天出现异动、Pearson 被拉低但 Spearman 仍高时，说明整体同向关系没变。

Kendall τ 秩相关

  • 定义：比较所有样本对的方向一致性。
  • 算法：τ =（一致对 − 不一致对）÷ 总对数，含并列修正（τ-b）。
  • 作用：小样本更稳健，对分布假设要求最低。
  • 注意：值通常比 Pearson 小，−0.3 的 Kendall 已经算较强关系，不要与 Pearson 直接比大小。

下行相关（同跌）

  • 定义：只取窗口内双方同时下跌的交易日计算相关性。
  • 算法：先过滤 x < 0 且 y < 0 的样本，再算 Pearson；样本少于 3 个时返回缺失。
  • 作用：衡量「一起跌」的程度。分散投资最怕的是下跌时同向，而不是上涨时同向。
  • 注意：只看下跌日，样本量比全样本少，波动更大。

波动相关（|收益|）

  • 定义：两个标的收益率绝对值之间的相关性。
  • 算法：对 |r| 序列计算 Pearson。
  • 作用：衡量波动是否共振——一个市场剧烈波动时，另一个是否也跟着剧烈波动，无论方向。
  • 注意：高波动相关、低方向相关，说明两者「同惊不同向」，适合对冲而非同向配置。

滞后相关（±1 日）

  • 定义：一个标的今天与另一个标的昨天（或反之）的相关性。
  • 算法：leadlag = [corr(Aₜ, Bₜ₋₁) + corr(Bₜ, Aₜ₋₁)] ÷ 2，取对称平均。
  • 作用：捕捉「谁领先谁一天」的传导关系。跨时区市场（如美股 vs A 股）常出现明显滞后相关。
  • 注意：对称平均会掩盖单方向领先；若需判断方向，可看下方「配对明细」。

综合关联指数

  • 定义：把上面 6 个指标按权重加权平均，得到一个统一读数。
  • 算法：
    综合 = Σ(wᵢ · metricᵢ) ÷ Σwᵢ（缺失的指标自动剔出并重新归一化权重）
    默认权重：Pearson 30%、Spearman 20%、Kendall 15%、下行 15%、波动 10%、滞后 10%。
  • 作用：避免单看某一个指标被极端值误导；一眼判断两个标的的整体联动强度。
  • 怎么调：关系里最关心下跌风险，就提高「下行相关」的权重。

相关性强度判定

|ρ| 范围判定含义
0 ~ 0.1基本不相关走势独立，分散效果好
0.1 ~ 0.3弱相关有微弱联动
0.3 ~ 0.6中等相关同向倾向明显
0.6 ~ 1.0强相关基本同涨同跌，分散作用有限
相关性不等于因果。高相关也可能是同受第三个因素（如美元流动性）驱动；相关系数也会随窗口切换而显著变化，20 日窗口的结论不要直接外推到长期。

3.3 资金流估算

个股资金流（流入 / 流出占比）

  • 定义：用当日 K 线的收盘位置估算买卖力量占比。
  • 算法：
    流入% = (收盘 − 最低) ÷ (最高 − 最低) × 100
    流出% = 100 − 流入%
    净流入% = 流入% − 流出%
    最高 = 最低（一字板或无波动）时按 50 : 50 中性处理。
  • 作用：在免费数据源没有逐笔成交的情况下，用价格在当日区间的位置近似「收盘时是谁占上风」。
  • 注意：这是估算，不是真实资金流向；只能横向比较强弱，不能当作绝对金额。

利率 / 债券的资金流

  • 算法：收益率没有成交量，改用日变动（bp）相对近 20 日波动的比例归一化到 ±100。收益率下行视为债券净流入，上行视为净流出。

市场资金流（净流入占比曲线）

  • 定义：把一个市场内所有标的的日资金流按市值加权汇总后的累计曲线。
  • 算法：市场内每个标的取 3.3 的净流入%，按总市值加权平均，再按日累加。
  • 作用：观察资金在 A股 / 港股 / 美股 / ETF / 期货 / 债券 / 利率 / 汇率 之间的相对流向。

3.4 LightGBM 概率预测

它预测什么

给定用户选定的 N 个指标，预测目标指标（第一个选中的）下一期相对上一期的涨跌幅落在各个区间的概率。

输入特征

  • 每个指标取 t-1 及之前 T 个交易日的日收益率（T 默认 20，可调 5~120）；
  • 再加每个指标 T 期收益率的标准差（波动率）；
  • 特征总数 = N × (T + 1)，例如 3 个指标、T=20 → 63 个特征。

目标与分档

  • 目标值 = 目标指标在 t 时刻的日收益率；
  • 按训练集分位数切成 K 档（默认 6 档），保证每档样本量接近，避免极端档样本过少；
  • 档位标签如「低于 −0.44%」「−0.44% ~ 0.05%」「高于 0.53%」，负值档为下跌、正值档为上涨。

模型与训练

  • LightGBM 多分类（原生 API），260 轮、学习率 0.05、num_leaves 15、max_depth 5；
  • 按时间顺序切分：前 80% 训练、后 20% 测试，绝不随机打乱，避免未来数据泄漏；
  • 输出前做 25% 先验收缩：概率 = 0.75 × 模型 + 0.25 × 训练集分布，抑制树模型过度自信。

怎么读结果

字段含义
各档概率该区间相对更可能出现，不是收益承诺；各档概率之和为 100%。
测试集准确率在没参与训练的最近 20% 数据上，猜中档位的比例。
多数类基线「永远猜样本最多那一档」的准确率。只有明显高于基线才有参考价值。
特征贡献按 gain 归一化的前几名特征，能看出模型主要依赖哪个指标/哪一天。
引擎标识绿色 LightGBM 表示用的是真模型；黄色「内置逻辑回归」表示 LightGBM 未加载（会显示原因）。
金融时间序列可预测性天然很低。准确率 25%~35% 在 6 档分类里已属正常水平；不要把它当作交易信号，更不要据此加杠杆。

3.5 宏观指标

指标定义 / 算法作用与注意
GDP（现价美元）世界银行年度现价美元 GDP衡量经济体量，用于筛选与排序；年度数据，不反映季度波动
GNI（人均）国民总收入 ÷ 人口比人均 GDP 更贴近居民收入水平
GDP 同比本年 GDP ÷ 上年 GDP − 1看增长动能；受基数影响大
失业率ILO 口径失业人口 ÷ 劳动力就业松紧；各国统计口径略有差异
政府债务 / GDP一般政府总债务 ÷ 当年 GDP财政空间；超过 100% 并不必然危机，但制约刺激能力
广义货币 / GDPM2（或各国口径）÷ GDP金融深化程度与流动性存量
CPI 同比CPI 指数同比通胀水平；影响货币政策预期
政策利率各国央行基准利率，人工维护标注了截止月份；不要当作实时值

3.6 债券指标

  • 国债收益率：2Y / 5Y / 10Y / 30Y 到期收益率，反映市场对增长、通胀与政策的定价。
  • 期限利差：10Y − 2Y。倒挂（负值）历史上常被视为衰退前兆，但不是必然。
  • 美债发行量：按 Bill（≤1 年）/ Note（2~10 年）/ Bond（≥20 年）分类的月度发行规模，反映财政融资压力与供给冲击。
  • 数据源：中国国债收益率来自东方财富（偶尔限流，缺失时曲线会提示）；美国来自 CNBC 实时报价，缺失时用最近收盘价兜底。

3.7 黄金指标

  • 黄金储备（吨）：世界银行「总储备 − 不含黄金储备」得到黄金的美元价值，再按当年金价折算成吨数。
  • 年度净买卖：储备吨数的同比变化。正值＝净买入，负值＝净卖出。
  • 占外储比例：黄金储备市值 ÷ 总储备。
  • 内外价差：上海金（元/克） − 伦敦金（美元/盎司） × USD/CNY ÷ 31.1035。正值表示国内溢价（常见于汇率贬值预期或国内需求旺盛）。

3.8 板块指标

  • 行业涨跌幅：成分股市值加权的涨跌幅，Σ(个股涨跌幅 × 市值) ÷ Σ市值，避免小盘股拉偏。
  • 树图面积：个股总市值；颜色：涨跌幅（红涨绿跌，±6% 封顶，防止极端值吃掉色阶）。
  • 证监会口径层级：门类（19）→ 次类（制造业专有）→ 大类（30+）。门类点名称看聚合热力图，点箭头只展开/收起。
  • 新浪行业口径：49 个行业；金融被拆成银行 / 证券 / 保险 / 多元金融，按名称与名单规则归类。
  • 美股口径：纳斯达克 sector（13 个板块、近 7000 只股票）。

6 软件更新与版本规则

  • 检查更新：工具栏按钮，对比本地构建与远端仓库的最新提交。
  • 判定方式：用 git 提交判断新旧（比版本号精确，能识别同一版本号下的多次修补），版本号只用于展示与沟通。
  • 下载：按 ghfast.top → gh-proxy.com → ghproxy.net → 直连 → jsDelivr 顺序尝试，支持断点续传，界面会显示当前使用的镜像。

  • 版本号：MAJOR.MINOR.PATCH。不兼容变更升 MAJOR，新增功能升 MINOR，修复升 PATCH。

7 常见问题

Q1：页面显示「无法连接」或一直转圈？

先看 data\app.log 末尾。常见原因是浏览器窗口比服务先退出，重新打开程序即可；也可能是某个数据源临时不可用，其他视图不受影响。

Q2：某个指标显示「—」？

代表该数据源本次没返回（限流、休市、接口调整）。程序不会用 0 填充，避免误导。

Q3：板块页切到「证监会」是空的？

说明 data\industry_map.csv 缺失。重装后首次启动会自动生成；也可以运行 python run.py pdf-import 从 PDF 重新解析。

Q4：LightGBM 显示「内置逻辑回归」？

说明运行环境没有加载到 LightGBM（标签悬停可看具体原因）。功能仍可用，但模型换成内置的逻辑回归，精度与特征贡献会缺失。

Q5：历史数据能保存多久？

本地库按需累积，日线默认保留全部已下载记录；「下载历史」可一次性补齐全部标的。

Q6：可以离线使用吗？

已下载过历史的标的可以离线查看日线与板块；实时报价、宏观、更新检查需要联网。
